# EmoAI Frontend

EmoAI is an AI-powered emotional companion platform focused on emotional support, journaling, mood tracking, and reflective AI conversations.

## Features

- AI emotional companion chat
- Secure login/signup authentication
- Mood tracking dashboard
- Reflective journaling
- Emotional analysis integration
- Responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Vercel (Deployment)
